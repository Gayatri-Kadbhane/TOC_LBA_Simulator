02 • METHODOLOGY

How the LBA Works

The simulator uses the mark-and-match strategy described in the case study.

01

Validate Input

Check whether the input contains only a, b and c and follows the required order a*b*c*.

02

Mark a

Find an unmarked a and replace it with X.

03

Match b

Move right and find an unmarked b. Replace it with Y.

04

Match c

Find an unmarked c and replace it with Z.

05

Return

Move the head back toward the left side of the bounded tape.

06

Accept / Reject

If all symbols are matched, accept. Otherwise reject.

→

03 • THEORY

Core Concepts

Σ

Formal Language

A set of strings constructed from symbols according to defined rules.

Σ = {a, b, c}
1

Type 1 Language

Context-Sensitive Languages belong to Type 1 in the Chomsky hierarchy.

CSG → LBA
▣

Linear Bounded Automaton

An LBA works within tape space linearly bounded by the input size.

Space = O(n)
≈

Target Language

Equal numbers of a, b and c must appear in the correct order.

aⁿbⁿcⁿ

LBA States

State Purpose
q0 Initialization
q1 Find an unmarked a
q2 Find matching b
q3 Find matching c
q4 Return toward the left side
q_accept Accept input
q_reject Reject input
